# Pre-registered sensitivity screen for the full cash model

This directory contains a separate screening experiment. It leaves the manuscript and `full_model_example/run.py` unchanged. The DGP is the complete nonlinear H/A/V cash model from `verify_structural_weak_score.model`: 12 periods, margin 0.1, operating expense 3, fixed baseline means and covariance. The known population mean/covariance and deployment measurement-noise matrix are used by the fitted policies; this isolates learning of the weak-score coefficient, as in the parent full-model example.

The fixed cash grid is the Cartesian product of a common deployment measurement-noise multiplier `D_A=D_V in {1,4,16}` and CAC prices `{25,75,150}` (nine scenarios). Both activity and turnover deployment noise variances are scaled together; churn-score noise stays at baseline. For every cash scenario, the true score coefficient is fixed at `tau=0.25`, and fitted tau is clipped to `[-1,1]`. Score strength and deployment quality are held fixed while pilot size varies over `{64,512,4096}`. Independently, H-reference noise variance is multiplied by `D_H in {1,4,16}`. Thus `D_A=D_V` changes deployment information in W, while `D_H` changes calibration-reference quality; neither is treated as a proxy for the other.

The incremental response uses the previously fixed application gate `(-3.200874778243636, 2.7545876756152166, 3.0)` from `full_model_example/run.py` (activity-score bounds and absolute X limit). Baseline profit uses the full accepted conditional-normal region. The gate cash response is evaluated on the pre-fixed 41-point equally spaced grid on `[-1,1]`, with `WeakBoundaryEngine` orders outer=10, inner=14 and vertical=10. Expected baseline profit is separately integrated over the accepted conditional-normal region using `BoundaryEngine` and vertical order 10. The screening response is interpolated by PCHIP. For each of the nine `(N,D_H)` combinations, 100,000 independent draws are generated from the exact Bartlett/Wishart law of the sample covariance estimator for a bivariate normal pair `(X, mean H reference)`, then clipped to `[-1,1]` and mapped through that interpolation. One fixed seed is used. This is a pre-fixed, low-order screening grid; it is not a high-precision numerical result or an empirical plausibility claim.

The report records mean incremental profit per 100,000 incoming candidates, Monte Carlo standard error of that mean, the mean as a percentage of baseline profit, baseline profit, clipping rate, and whether any points in the fitted-tau response failed the engine's upward-crossing certificate or root bracketing. Certification failures are surfaced; no high-precision claim is made for this screen. These parameter combinations define an interpretable sensitivity region that requires product data to assess empirical plausibility.

Run from the project root with `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 full_model_example/sensitivity/run_sensitivity.py`. Results and intermediate curve checkpoints are written only in this directory.
