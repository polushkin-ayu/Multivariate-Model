# Численная проверка теоремы 1

Проведена прямая проверка на исходной модели `verify_structural_weak_score.model()` и функции выборки `verify_structural_weak_score.sample()`. Для каждого обучения функция `structural_weak_score.fit()` совместно оценивает параметры общей модели по двум независимым референсам и силу нового скора. Для CAC=25 рассчитан точный интегральный прирост прибыли полного правила внутри фиксированной симметричной области из `verify_gated_weak_score.py`.

Использованы N ∈ {2 000, 20 000, 100 000}, h/s ∈ {0.5, 2}, по 128 обучений на ячейку; генератор NumPy PCG64 и seed 2026101417 зафиксированы до первого обучения. В каждой репликации сопоставлены интегральная величина `N × gain(fitted, tau, 1)` и предсказание `C(2 h T − T²)`, где T=√N τ̂. Единицы в таблице и на парном графике — безразмерные эффекты после деления на C s². Пределы ожидания по теореме для двух отношений h/s равны соответственно −0.75 и 3.

Парные значения и сводка сохранены в `paired_gains.npz` и `summary.json`. MC SE относится к среднему по 128 обучений, а не к разбросу индивидуальных эффектов. Средний абсолютный остаток убывает с N для обоих h/s. Пределы ожиданий по теореме составляют −0.75 и 3; при 128 повторах средние эффекты колеблются вокруг этих значений.

Стабилизация общей модели, обрезка τ и ремонт ковариации не сработали ни в одной из 768 репликаций. Для C разность между порядками квадратуры 32×32 и 44×40 равна `C_gate_quadrature_absolute_difference` в `summary.json`. В каждой из шести ячеек первая репликация дополнительно проверена порядками 24×32; абсолютные различия интегрированного масштабированного выигрыша составили от 1.0×10⁻⁹ до 6.8×10⁻⁸.
