# Подробный сценарий полной модели

Текущая демонстрация в рукописи. Сценарий выбран после просмотра заранее заданной сетки: множитель дисперсий ошибок базовых скоров4, CAC75, дисперсия ошибки референса ухода4, истинная сила скора0.25, пилот64. Это интерпретируемый синтетический сценарий; эмпирическая распространённость параметров не установлена. Относительно исходной точки сетки изменены и шум, и CAC — потерю нельзя приписать только одному из них.

Общие параметры μ,Σ,D известны. Оценивается только τ по двум независимым H-референсам и X; оценка ограничивается[-1,1]. Сохраняются исходные параметры поведения и фиксированная область применения нового скора. Прогнозы интегрируют полную нелинейную денежную модель.

- Отношение ожидаемой прибыли к ожидаемому CAC42.8505% →42.1344%: −0.7162 процентного пункта.
- Доля калибровок с ухудшением67.43%; q05/q95 эффекта−42117.40 и+3195.57. Портфельная случайность поведения усреднена.
- При N512 средний эффект+981.17; при N4096 +2965.70. τ остаётся0.25.
- При N64 необрезанная оценка несмещённа, её стандартное отклонение0.638705. Среднее после ограничения0.217170, bias−0.032830; эти значения отдельно рассчитаны интегрированием, не взяты из случайного MC-среднего.

## Точность

161 коэффициент в денежной кривой; 200000 независимых выборок из точного закона оценки на каждый из38 размеров N. Повышение всех трёх порядков квадратуры с(18,24,16) до(28,36,32) на17 промежуточных точках даёт max change0.47989 попугая на100000. 95%-я MC-полуширина для среднего при N64 равна59.52 попугая. Это разные источники погрешности; численная проверка является диагностикой, не строгой границей. Дополнительные кривые качества референсов используют тот же закон и200000 калибровок на точку.

## Воспроизведение из корня проекта

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 full_model_example/refined/run.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 full_model_example/refined/validate.py
python3 full_model_example/refined/render.py
OPENBLAS_NUM_THREADS=1 python3 full_model_example/refined/business_plots.py
OPENBLAS_NUM_THREADS=1 python3 full_model_example/bias/calculate.py
```

`results.json` — на одного кандидата; `business_metrics.json` — на100000. `curve_checkpoint.json` относится только к текущей спецификации; при иных параметрах его нельзя повторно использовать. Гистограмма прибыли детерминированно воспроизводит тот же поток RNG, что основной расчёт N64. `reference_quality.json` содержит отдельные расчёты при трёх уровнях шума калибровочных референсов. Код и PNG/PDF рисунков сохранены рядом.
